# MaterialAttestation - Учёт материалов предприятия

Учебный проект по системному программированию на Python.

## Описание

Приложение для учёта материалов предприятия с графическим интерфейсом на Tkinter и базой данных SQLite.

## Возможности

- Просмотр списка материалов
- Добавление материалов
- Редактирование записей
- Удаление с подтверждением
- Поиск по наименованию
- Пагинация (20 записей на странице)
- Проверка корректности вводимых данных
- Обработка ошибок базы данных

## Структура проекта

- `app.py` - графическое приложение
- `database.py` - подключение к SQLite
- `import_data.py` - импорт данных
- `db/schema.sql` - SQL-схема
- `db/materials.sqlite3` - база данных
- `docs/er_diagram.pdf` - ER-диаграмма
- `tests/test_database.py` - автоматические тесты

## Запуск

Требуется Python 3 с поддержкой Tkinter.

Открыть терминал в папке проекта и выполнить:

```bash
python app.py
```

На Windows также можно использовать:

```bash
py app.py
```

## Тестирование

```bash
py -m unittest discover -s tests -v
```

При последней локальной проверке все 10 тестов завершились успешно.
